Siblings

Views opened from the same parent are siblings. Zumly moves between them sideways, without zooming out first.

Live exampleOpen ↗

Open a zone, then use the arrows or the dots at the bottom, or swipe left and right.

The code

const zone = (title, depth, text) => `
  <div class="z-view card" data-title="${title}">
    <h2>${title}</h2><small>${depth}</small><p>${text}</p>
  </div>`

const app = new Zumly({
  mount: '.canvas',
  initialView: 'ocean',
  views: {
    ocean: `<div class="z-view ocean" data-title="Ocean">
              <div class="zoom-me zone" data-to="sunlight">Sunlight zone</div>
              <div class="zoom-me zone" data-to="twilight">Twilight zone</div>
              <div class="zoom-me zone" data-to="midnight">Midnight zone</div>
            </div>`,
    sunlight: zone('Sunlight zone', '0–200 m', 'Light, plants and most of the fish.'),
    twilight: zone('Twilight zone', '200–1000 m', 'Dim blue light. Many animals glow.'),
    midnight: zone('Midnight zone', '1000 m and deeper', 'No sunlight. The anglerfish brings its own.')
  },
  // A horizontal swipe moves to the next or previous sibling
  lateralNav: { swipe: true }
})
app.init()

How it works

  • Siblings are found for you: they are the views of the other triggers in the parent. The slide direction follows where those triggers sit.
  • The sibling bar appears when the current view does not cover the canvas. lateralNav: { mode: 'always' } shows it on full-screen views too.
  • swipe: true makes a horizontal swipe move between siblings. Where there are none, a swipe left still zooms out.
  • back() first undoes the sideways moves at this level, then zooms out.

To set the order yourself, or keep siblings alive in the DOM while you move between them:

lateralNav: {
  siblings: { ocean: ['sunlight', 'twilight', 'midnight'] },
  keepAlive: true,   // form fields and scroll positions survive
  swipe: true
}

Siblings are told apart by view name. Several triggers that open the same view with different data-* are one view, not siblings. That pattern is in the next step.
