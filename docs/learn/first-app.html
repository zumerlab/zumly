Your first app

A Zumly app is a canvas, a map of named views, and triggers that zoom from one view into the next.

Live exampleOpen ↗

Click the O. To come back, click outside the circle, press the button at the bottom left, scroll down or press ArrowLeft.

The code

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Hello Zumly</title>
  <link rel="stylesheet" href="https://unpkg.com/zumly/dist/zumly.css">
  <script src="https://unpkg.com/zumly/dist/zumly.js"></script>
  <style>
    body { margin: 0; font: 20px system-ui, sans-serif; }
    /* The canvas fills its nearest positioned ancestor: give it a size. */
    .stage { position: relative; height: 100vh; }
    .z-view { display: grid; place-items: center; }
    .hello { width: 100%; height: 100%; }
    .world { width: 320px; height: 320px; border-radius: 50%; background: #3da9fc; color: white; }
    .zoom-me { cursor: zoom-in; font-weight: bold; }
  </style>
</head>
<body>
  <div class="stage">
    <div class="canvas zumly-canvas"></div>
  </div>
  <script>
    const app = new Zumly({
      mount: '.canvas',
      initialView: 'hello',
      views: {
        hello: `<div class="z-view hello">
                  <p>H E L L O &nbsp; W <span class="zoom-me" data-to="world">O</span> R L D</p>
                </div>`,
        world: `<div class="z-view world">Hi from inside the O</div>`
      }
    })
    app.init()
  </script>
</body>
</html>

How it works

  • The canvas is the element with class zumly-canvas. It fills its nearest positioned ancestor, here .stage, so that ancestor needs a height.
  • Views are the screens. views maps a name to its HTML, and the root of each view has class z-view. Each view sets its own size: hello fills the canvas, world is a 320 px circle.
  • A trigger is any element with class="zoom-me" and data-to="name". Clicking it scales the current view until the trigger covers the new one, so the new view seems to grow out of it.
  • initialView is the first view, and app.init() renders it.

Install

The example loads Zumly from a CDN, so you can save it as a file and open it. With a bundler:

npm install zumly
import Zumly from 'zumly'
import 'zumly/style.css'

Keep the browser console open while you build. Zumly explains its mistakes there: a data-to that names no view, an option with a typo, or a canvas with no height.
